# Research session entry point

Read `EXECUTION_STATE.json`, `STATUS.md`, `CLAIMS.md` and `NEXT_ACTION.md`
before work, then the relevant referenced protocol and development records.
The canonical state retains prior invalid, negative and exploratory findings;
read its closed amendments before creating a new finite session.

Update the canonical state and append the actual source identities, verification,
failures, decisions and remaining gates before finishing. Preserve previous
records, consumed lockbox status and frozen sources. Software tests do not
qualify a scientific claim, authorize external submission or mark research done.
