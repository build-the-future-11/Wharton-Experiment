# Data intake contract

`intake.py` reads only the seven prospectively frozen `*.us.txt` ETF files SPY, IWM, DIA, TLT, IEF, GLD and SLV from the Huge Stock Market Dataset. Version 0.1.9 excludes QQQ solely because the pre-market 0.1.8 source audit found that its exact file contains 2011-02-17 while all seven retained files omit that date; no historical model cell had started. The successor allowlists every retained source SHA-256. It checks one file per asset, dates, strict order, schema, finite positive OHLC, the OHLC envelope, nonnegative volume, exact byte identity, equal calendars and minimum history. Rows on/after the stop boundary are skipped before numerical parsing; older admitted rows are validated before selecting the start date. Exact row width, finite nonnegative integer open interest and finite derived features are required. No repair through future imputation or calendar intersection is permitted. Failure leaves `intake.json` with the reason.

Output `panel.csv` contains UTC calendar-order coordinates, asset, availability coordinate, backward return and eight numbered features: intraday ratio, overnight ratio, range/close, log1p volume, trailing5/20-observation mean, trailing20 volatility and downside semideviation. The first20 dates are warmup. No feature uses later observations. A manifest binds the CSV checksum and explicitly calls the return a `source_adjusted_close_ratio_not_verified_total_return`; availability is `historical_order_only_unverified_point_in_time`. The ingestion timestamp means the current package read the source files, not an invented original publication date.

The generic strict total-return CSV contract remains available for genuinely audited data. Its manifest must assert complete simple total returns including terminal outcomes and availability bounding all features. Neither that assertion nor the proxy declaration independently proves provider rights or historical validity.

`asof_values` implements a release-time vintage join. Unknown timestamps, ambiguous revisions and nonfinite values fail; decisions before first publication have no value. It chooses the latest observation period known at the decision, then its latest available revision, so a revision to an old period cannot overwrite a newer observation. The source must provide actual publication times. Current FRED-MD vintages and current SEC companyfacts must not be backfilled by reporting-period end. No SEC or FRED data has yet been connected to this benchmark.

User-suggested additional sources are retained as separate admission work: Jacksoncrow prices need their own schema/adjustment and cohort audit; Jane Street anonymous targets require a separate weighted-target task contract and competition access, not equity labels; FinancialPhraseBank sentiment labels lack usable historical event/asset timestamps; SEC and FRED require actual publication/vintage provenance. None is silently synthesized, represented as used, or claimed unavailable permanently. Scaling to all stocks requires delisting/identity/eligibility handling and a ragged-panel design; this eight-ETF balanced adapter does not claim to solve it.

A generic forecast decision must precede its first target observation strictly. Delayed features that violate that clock require a separately audited as-of adapter, not retrospective bar labels. Neither configuration nor adapter may move the protected boundary beyond 2025-01-01 UTC. Timestamp conversion uses integer microseconds without a floating-point epoch round trip.
